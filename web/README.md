# Web UI Dashboard & State Machine Visualizer

Provides a visual interface to the 22-state compiler pipeline.

## Features
- **22-State Pipeline Track**: Visual state node progression reflecting real-time state machine transitions.
- **Untrusted Source Ingestion**: Code editor with preset C++ numeric kernels and mode selection.
- **Emergency SAFE_STOP**: High-visibility instant halt button.
- **Verification Gates Telemetry**: Correctness, security, canary, and speedup metrics.
- **Side-by-Side IR Diff Viewer**: Inspects Candidate 0 baseline against accepted candidate IR.
- **Provenance & Audit Explorer**: Displays cryptographic certificate and append-only audit trail.
